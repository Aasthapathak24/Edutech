# EduTech - Institute Management System

EduTech is a conceptual web-based Institute Management System developed as an academic project using PHP and MySQL.

The system is designed to provide students with a centralized platform for accessing institute-related and academic information.

## Features

- Student registration
- Result verification and confirmation
- Attendance login and attendance records
- Academic results
- Assignments
- Courses
- Announcements
- Admission status

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## Project Overview

The project was developed to gain practical experience in building a dynamic, database-driven web application.

The system includes different sections for student registration, attendance, results, and other academic and institute-related information.

PHP is used for server-side functionality, while MySQL is used to store and manage project data.

## How to Run the Project

1. Install XAMPP on your computer.
2. Place the project folder inside the `htdocs` directory.
3. Start Apache and MySQL using the XAMPP Control Panel.
4. Open phpMyAdmin.
5. Import the project database into MySQL.
6. Open a web browser.
7. Navigate to the project using your local XAMPP server.

Example:

`http://localhost/EduTech/`
